# HTTP Surface and Form Actions (Examinai)

This application is **server-rendered** (Thymeleaf). “API” here means **browser-facing HTTP routes**: GET pages and POST form actions. There is no separate JSON REST API for the main product UI.

**Authentication:** Spring Security **form login** (`/login`), session cookie, **CSRF** on POSTs (default). Role rules mirror `SecurityConfig` (see [architecture.md](./architecture.md)).

## External integration (not browser routes)

- **Ollama:** HTTP client from `spring-ai-starter-model-ollama` to `OLLAMA_BASE_URL` (e.g. `http://127.0.0.1:11434`).
- **Git provider:** `GitSourceClient` uses Spring `RestClient` against `GIT_PROVIDER_BASE_URL` (GitHub REST v3–compatible).
