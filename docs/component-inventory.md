# Component Inventory — UI and Web Layer

The product UI is **server-rendered**. Components are **Thymeleaf templates** and **static assets**; there is no React/Vue component tree.

## Template layout (`JAVA_APP/src/main/resources/templates/`)

| Area | Templates | Notes |
|------|-----------|--------|
| Core | `index.html`, `home.html`, `login.html` | Entry and auth |
| App shell | `app/secure.html` | Authenticated smoke |
| Admin | `admin/users/list.html`, `admin/user-form.html` | User CRUD |
| Coordinator | `coordinator/index.html`, `coordinator/case-record.html` | Case visibility |
| Intern | `intern/tasks/list.html`, `intern/tasks/detail.html`, `intern/submissions/feedback.html` | Tasks and feedback |
| Mentor / tasks | `tasks/list.html`, `tasks/form.html`, `tasks/assign.html`, `tasks/submissions.html`, `tasks/submission-detail.html` | Task lifecycle and mentor workspace |
| Review | `review/queue.html` | Mentor queue |
| Fragments | `fragments/head-bootstrap.html`, `fragments/welcome-scripts.html`, `fragments/head-welcome-jqui.html` | Shared head/scripts |
| Task fragments | `tasks/fragments/git-retrieval.html`, `tasks/fragments/degraded-inference-banner.html` | Partial includes |
| Intern fragments | `intern/fragments/submission-lifecycle-badge.html` | Status badge |

## Third-party UI (WebJars)

Declared in `pom.xml` and referenced from templates:

- **Bootstrap** 5.3.3
- **jQuery** 3.7.1
- **jQuery UI** 1.13.2

Typical inclusion via `fragments/head-bootstrap` and WebJar URLs under `/webjars/`.

## Server-side “components”

| Type | Location | Role |
|------|----------|------|
| Controllers | `com.examinai.app.web.*` | Map URLs to views and form handlers |
| Controller advice | `DegradedInferenceModelAdvice` | Adds degraded LLM attributes for mentor controllers |
| Forms | `*Form` classes in web packages | Binding and validation for POST bodies |

## Design system

- **Bootstrap 5** for layout and components (no CDN; WebJars per README story 8.1).
- **Thymeleaf** layout composition via `th:replace` / fragments.
