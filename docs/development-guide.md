# Development Guide — Examinai

## Prerequisites

- **JDK 21** or newer
- **Maven** or **`./mvnw`** (wrapper included)
- **PostgreSQL** for the `dev` profile (local install or Docker)
- Optional: **Docker Compose v2** for full pilot stack (app + Postgres + Ollama)

## Configuration

- Base settings: `JAVA_APP/src/main/resources/application.yml`
- Profile overrides: `JAVA_APP/src/main/resources/application-{dev,test,prod}.yml`
- **Secrets via environment** — see **`JAVA_APP/.env.example`** for `SPRING_DATASOURCE_*`, `GIT_PROVIDER_*`, `OLLAMA_*`, and Examinai-specific tuning (`EXAMINAI_*`).

Do not commit tokens or production passwords.

## Local database (quick)

Example from README:

```bash
docker run -d --name examinai-pg \
  -e POSTGRES_USER=examinai \
  -e POSTGRES_PASSWORD=examinai \
  -e POSTGRES_DB=examinai \
  -p 5432:5432 \
  postgres:16-alpine
```

Default JDBC for `dev`: `jdbc:postgresql://localhost:5432/examinai` with user/password `examinai` unless overridden.

## Run the application (dev)

From the **`JAVA_APP/`** directory (where `pom.xml` and `mvnw` live):

```bash
cd JAVA_APP
./mvnw spring-boot:run -Dspring-boot.run.profiles=dev
```

Health check:

```bash
curl -sSf http://localhost:8080/actuator/health
```

## Build without tests

```bash
cd JAVA_APP
./mvnw -DskipTests package
```

## Run tests

```bash
cd JAVA_APP
./mvnw test
```

Integration tests may use **Testcontainers** (PostgreSQL) and require Docker where applicable.

## Ollama (optional for AI flows)

- Set **`OLLAMA_BASE_URL`** and **`OLLAMA_MODEL`**
- Ensure the model is pulled on the Ollama host (`ollama pull <tag>`)
- Spring AI can auto-pull when missing (`pull-model-strategy: when_missing` in base YAML; tests override)

## Git integration (optional)

Set **`GIT_PROVIDER_BASE_URL`** (e.g. `https://api.github.com`) and **`GIT_PROVIDER_TOKEN`** for private repos or higher rate limits.
